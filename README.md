## 🚀 Projetos em Destaque

### [RESTful Booker API Test Automation with Playwright](https://github.com/mateus-f/playwright-restful-booker-api)

Projeto de automação de testes de API REST com Playwright, utilizando Service Object Model (SOM), BDD/Gherkin, fixtures, factories e validação de contratos com JSON Schema. Conta com execução em CI/CD via GitHub Actions e relatório publicado no GitHub Pages.

[Ver relatório de testes](https://mateus-f.github.io/playwright-restful-booker-api/)

### [Confirmed Seat REST API Development with Spring Boot](https://github.com/mateus-f/confirmed-seat-api)

API REST para gerenciamento de inscrições e reservas de vagas, desenvolvida com Java e Spring Boot. Implementa autenticação JWT, controle de acesso, regras de negócio e persistência com PostgreSQL.
